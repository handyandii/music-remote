# Changelog

## 1.1.0

- Fully rebindable controller input: bind any button, trigger, stick or D-pad input to a
  media action, including inputs that only report as analog axes.
- Multiple named binding profiles.
- Controller test screen showing the raw input the device detects.
- Full colour picker in the custom theme builder, alongside swatches and hex input.
- Visualizer bar count and bar width settings.
- Track title animation when skipping tracks (can be turned off).
- Much smaller download: about 3 MB, down from about 49 MB.

## 1.0.0

- Initial version.
